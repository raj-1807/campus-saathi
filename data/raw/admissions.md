# Admission Knowledge

B.Tech admission is completed through online registration, entrance score submission,
document upload, counselling, seat allotment, fee payment, and physical verification.

Required documents include Class X marksheet, Class XII marksheet, entrance scorecard,
migration certificate, character certificate, category certificate if applicable,
Aadhaar card, and passport-size photographs.

Students should check application deadlines, counselling schedule, eligibility criteria,
fee payment date, and hostel allocation notice before admission confirmation.
